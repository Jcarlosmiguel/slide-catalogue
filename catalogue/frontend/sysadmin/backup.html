Backup

Creates a new full database backup, written to catalogue/backups/database/full/ on the server. Only ever creates a new file - existing backups are never listed, read, or deleted from here. There is no restore facility on this page or anywhere in the web app: restoring a backup is a deliberate, command-line-only operation on the host. Visible to system administrators only.
