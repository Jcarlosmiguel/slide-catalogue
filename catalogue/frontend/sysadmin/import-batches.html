Import Batches

Uploads a matching .sql/.report.txt/.run.log trio from an external crawler tool (see this repo's catalogue/docs/import-batches.md for the expected file format) and walks through resolving anything left ambiguous, recording where the batch came from, committing the import, and generating thumbnails for the newly-imported slides. Visible to system administrators only.

Before generating the .sql: the physical_path it writes for each slide must be a path this catalogue's own backend container can open, not a path on whatever machine generated the file - these are often different mount points for the same archive. Getting it wrong doesn't block the upload or commit, but thumbnail generation will fail with "Unable to open slide" until it's corrected. See catalogue/docs/import-batches.md for the full explanation and an example.
