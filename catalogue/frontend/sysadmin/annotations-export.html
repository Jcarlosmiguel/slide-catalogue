Annotations export

Downloads one OME-XML file per slide that has at least one non-flagged annotation, bundled into a single zip - the same per-slide OME-XML a slide's own page can generate individually (see applying a slide's annotations), just all of them in one archival run. Uses fixed defaults for every slide: bright green, arrowhead at the start for "arrow"-type annotations. Visible to system administrators only.
