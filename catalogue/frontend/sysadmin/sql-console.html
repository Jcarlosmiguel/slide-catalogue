SQL Console

Runs one SQL statement directly against the catalogue database - useful for one-off fixes (e.g. correcting a provenance field) that don't need a full page built for them. SELECT/UPDATE/DELETE/INSERT/ ALTER/CREATE etc. are allowed; DROP and TRUNCATE are blocked, and only one statement may be run at a time. Every statement that changes data is written to the Audit Log; plain SELECT queries are not. Visible to system administrators only.
