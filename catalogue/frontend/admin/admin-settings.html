DICOM De-identification Default

Site-wide default for how a DICOM slide's header is scrubbed of patient-identifying data before it's ever served. Applies whenever the catalogue itself needs to de-identify a DICOM file (e.g. one catalogued without already going through slide-crawler's own per-run de-identification step) - it never re-processes a slide that already has a mode recorded. Neither mode inspects pixel data, so a scanner-burned-in text overlay is not removed by either - always visually check a slide flagged with a burned-in annotation warning before making it available regardless of mode.
